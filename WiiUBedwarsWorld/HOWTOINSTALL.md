# ベッドウォーズの遊び方  
1. LunarSEv2のWorldタブから、チームMODとベッドウォーズプラグイン、ワールド保護を有効にします。  
2. ワールド保護の編集から、上2つのチェックボックスをチェックします。  
3. 人が集まったら、コマンド `/bedwars start <1チームあたり人数>` でスタートします。  
例えば、3v3にしたいなら `/bedwars start 3` で開始できます。

# 既知の問題  
1. ファイアーボールを投げた時、ネットから切断されワールドが落ちることがあるかもしれません。  
2. 特に参加チームが多い場合、ネットから切断されワールドが落ちることがあるかもしれません。  

# ワールドの導入・移動方法

ワールドをWii Uに導入し、Switchとの間で移動する方法を2通り紹介します。どちらの方法でも、移動作業中はLunarSE v2の`exefs`を一時的に外してください。

> [!IMPORTANT]
> 作業前に、Wii UとSwitchのワールドデータ、およびLunarSE v2の`exefs`をバックアップしてください。作業が終わったら、退避しておいた`exefs`を元の場所に戻してください。

## 方法1：Wii UとSwitchの間でワールドを移動する

1. 改造済みのWii Uに、このフォルダーにあるワールドを導入します。
2. SDカードからLunarSE v2の`exefs`を一時的に取り外します。削除する場合は、事前に別の場所へコピーして退避してください。
3. Wii UとSwitchでワールドを移動します。
4. 移動が完了したら、退避しておいた`exefs`を元の場所に戻します。

## 方法2：Windows向け専用アプリを使ってWii Uへ移動する

1. [Minecraft-WiiU-Save-Transfer](https://github.com/HINATIR/Minecraft-WiiU-Save-Transfer)をダウンロードします。
2. SDカードからLunarSE v2の`exefs`を一時的に取り外します。削除する場合は、事前に別の場所へコピーして退避してください。
3. ダウンロードしたアプリを使い、Wii Uとの間でワールドを移動します。
4. 移動が完了したら、退避しておいた`exefs`を元の場所に戻します。
